**Casing.** `snake_case` on the wire. Our TypeScript SDK exposes `camelCase` and handles the mapping.

**Amounts.** Decimal strings, always paired with an asset. Never floats.

**Pagination.** Cursor based: `limit` and `starting_after`, with `has_more` and `next_cursor` in the response.

**Versioning.** In the path. Additive changes ship without a version bump, so **clients must ignore unknown fields**, and enum values may be added at any time, so every `switch` needs a `default`.
